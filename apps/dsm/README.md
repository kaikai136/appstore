## 产品介绍

**DSM** 基于网页的DSM桌面访问存储系统，支持网页浏览和 WebDAV 的文件列表程序，在 Docker 容器中虚拟 DSM。。

## 要求
 - 在支持KVM的Linux主机上使用Docker或Podman。
 - Windows 11 上的 Docker Desktop 或 Podman（桌面）启用嵌套虚拟化。
 - 至少有1GB的可用内存。
 - 至少有16GB的空闲磁盘空间。


> Linux、macOS 和 Windows 10 上的 Docker Desktop 目前不支持容器的 KVM 访问，因此不被支持。

## 特色

    - 在 Docker 容器内运行虚拟 DSM
    - 安装文件的自动下载
    - 基于网页的DSM桌面访问
    - 近乎原生的性能，配合KVM加速
    - 可定制的CPU、内存和存储分配
    - 支持多盘和物理盘直通
    - 动态内存分配与内存气泡化
    - 支持 NAT、用户模式、macvlan 和 macvtap 网络
